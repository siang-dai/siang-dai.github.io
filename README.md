## Publish

1. Name the GitHub repository exactly `siang-dai.github.io`.
2. Push these files to the `main` branch.
3. In GitHub: Settings → Pages → Source → GitHub Actions.
4. Open the Actions tab and run `Publish academic website` if it has not run automatically.
